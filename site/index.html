Mu-Linux Browser Text Game

Juego de navegador de MU Online, por texto y por turnos. Es una reescritura completa, sobre PHP 8.4 y MySQL 8.4, del juego de navegador de 2011: mismo espíritu y misma estética, con el contenido llevado hasta la Season 5. Se juega desde cualquier navegador y se levanta con un solo comando de Docker, en x64 o ARM64.

A text-based, turn-based MU Online browser game. It is a full rewrite, on PHP 8.4 and MySQL 8.4, of the 2011 browser game: same spirit and same look, with the content brought up to Season 5. It plays in any browser and starts with a single Docker command, on x64 or ARM64.

InstalarloInstall itInstalar

Sólo hace falta Docker con el plugin Compose. Corre en x64 y en ARM64 (VPS Ampere o Graviton, Raspberry Pi 4/5 de 64 bits).

All you need is Docker with the Compose plugin. It runs on x64 and ARM64 (Ampere or Graviton VPS, 64-bit Raspberry Pi 4/5).

Só é preciso o Docker com o plugin Compose. Roda em x64 e ARM64 (VPS Ampere ou Graviton, Raspberry Pi 4/5 de 64 bits).

curl -O https://raw.githubusercontent.com/EmanuelCatania/Mu-Linux-Browser-Text-Game/main/Mu-Browser/docker-compose.images.yml
docker compose -f docker-compose.images.yml up -d

El juego queda en http://localhost:8086. La primera vez, el código para crear la cuenta de administrador aparece en docker compose logs mu-web.

The game runs at http://localhost:8086. On the first run, the code to create the admin account is shown by docker compose logs mu-web.

O jogo fica em http://localhost:8086. Na primeira vez, o código para criar a conta de administrador aparece em docker compose logs mu-web.
